MTN MoMo Payment Gateway - Installation Guide
================================================

System Requirements
-------------------
- PHPNuxBill hotspot billing system (v6.x or later)
- PHP 7.4 or higher (recommended 8.0+)
- cURL extension enabled
- JSON extension enabled

Installation Steps
------------------

1. BACKUP YOUR SYSTEM
   Before installing, create a full backup of your PHPNuxBill installation and database.

2. COPY FILES
   Copy the following files from the `system/` directory in this package
   to your PHPNuxBill installation's `system/` directory:

   FROM (this package):                  TO (your PHPNuxBill):
   system/paymentgateway/mtnmomo.php  →  system/paymentgateway/mtnmomo.php
   system/paymentgateway/ui/mtnmomo.tpl → system/paymentgateway/ui/mtnmomo.tpl

   Your PHPNuxBill directory should look like:
   ```
   phpnuxbill/
   ├── system/
   │   ├── paymentgateway/
   │   │   ├── mtnmomo.php          ← NEW: Gateway logic
   │   │   ├── ui/
   │   │   │   ├── mtnmomo.tpl      ← NEW: Admin config template
   │   │   │   └── ... (existing files)
   │   │   └── ... (existing gateway files)
   │   └── ...
   └── ...
   ```

3. SET FILE PERMISSIONS (Linux/Mac only)
   ```bash
   chmod 644 system/paymentgateway/mtnmomo.php
   chmod 644 system/paymentgateway/ui/mtnmomo.tpl
   ```

4. ACTIVATE THE GATEWAY
   - Log into your PHPNuxBill admin panel
   - Navigate to: Settings → Payment Gateways
   - You should see "mtnmomo" in the list of available gateways
   - Click on it to configure

5. CONFIGURE THE GATEWAY
   In the gateway settings page, fill in:
   
   - Environment: sandbox (for testing) or live (for production)
   - API User ID: Your UUID from MTN Developer Portal
   - Collection Subscription Key: Primary key from Developer Portal
   - API Key: Generated API Key from MTN Developer Portal
   - Currency: SSP (South Sudanese Pound)
   - Country Code: 211 (South Sudan)

6. TEST IN SANDBOX MODE
   Before going live, test with sandbox mode:
   - Use the MTN Sandbox API to simulate payments
   - Verify that plans activate correctly after payment
   
7. GO LIVE
   Once testing is complete:
   - Change environment from "sandbox" to "live"
   - Update API credentials with production keys from MTN
   - Test with a real small-amount payment first

Troubleshooting
---------------

1. "Gateway not showing in admin panel"
   - Verify the file is at: system/paymentgateway/mtnmomo.php (NOT paymentgateway/mtnmomo.php)
   - Verify the template is at: system/paymentgateway/ui/mtnmomo.tpl
   - Check that the file has no PHP syntax errors: php -l system/paymentgateway/mtnmomo.php
   - Clear your browser cache and refresh

2. "Admin has not configured MTN MoMo payment gateway"
   - Go to Settings → Payment Gateways → mtnmomo
   - Fill in the API User ID and Collection Subscription Key

3. "Unable to authenticate"
   - Verify API credentials are correct
   - Check that your API User has been provisioned correctly
   - Ensure the subscription key matches the Collection product

4. "Payment was declined"
   - Customer may have insufficient MoMo balance
   - Phone number format may be wrong (should be 9XXXXXXXX for South Sudan)
   - Check the MTN MoMo API logs for details

Uninstallation
--------------
To remove the gateway:
1. Disable in PHPNuxBill admin panel (Settings → Payment Gateways)
2. Delete files:
   - system/paymentgateway/mtnmomo.php
   - system/paymentgateway/ui/mtnmomo.tpl
